# AGENTS.md — Self-Supplying Agent

You are building a tiny cozy three.js game. **You never ask the human for asset files.**
Every mesh, texture, sound and song comes from GMI Cloud, generated by you mid-session.

## Tools you have
- **GMI MCP server** (`.mcp.json` → `https://mcp.gmicloud.ai/mcp`, OAuth sign-in once).
  Tools: `search_models`, `get_model`, `estimate_generation`, `submit_generation`,
  `get_generation`, `list_generations`, `upload_media`, `get_account_summary`, `search_docs`.
- **Headless fallback**: `node pipeline/supply.mjs` does the same calls over the REST
  request queue with `GMI_API_KEY` from the environment (never commit it).

## Asset loop (do this whenever the game needs a new asset)
1. `search_models` for the modality (3d / image / audio).
2. `get_model` to read the real parameter enum. Don't guess values (they are case-sensitive).
3. `estimate_generation` and print the price.
4. `submit_generation`, then `get_generation` until `success`. Video/3D can take minutes.
5. Download `outcome.media_urls` into `assets/`, then append an entry to `assets/manifest.json`
   with `model`, `request_id`, `seconds`, and `cost_usd`.
6. Reference the asset from `src/main.js` **only via manifest ids**, never by a hard-coded path.

## Default models
| need | model | notes |
|---|---|---|
| game design / code | `google/gemini-4-carbon` (OpenAI-compatible, `api.gmi-serving.com/v1`) | JSON mode |
| 3D mesh | `hunyuan-3d-pro` | `generate_type` Normal/LowPoly, `face_count` ≥ 40000 |
| sprites | `gpt-image-2.5-flare-generate` | `background: "transparent"` |
| tileable textures / sky | `seedream-5.0-lite` | `size` WxH, 3.6M–10.4M px |
| soundtrack | `minimax-music-3.0` | `lyrics` with [Verse]/[Chorus] tags + style `prompt` |
| voice line | `minimax-tts-speech-2.8-turbo` | `voice_id`, `text` |

## Rules
- If a provider says `ResourceInsufficient` / "please retry", wait 45s and retry. Do not
  substitute hand-made or procedurally faked assets. If it stays down, fall back to the
  GMI sprite for that entity and say so in the manifest.
- Never print, log or commit the API key. `.env` and `.gmi_key` are git-ignored.
